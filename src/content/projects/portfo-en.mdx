## Result

- **3 days to the first version**, then ongoing iteration on the copy, the cases and the architecture.
- **Open source**: the only public repo among the projects shown, [RebSem/portfo](https://github.com/RebSem/portfo).
- **Stays current on its own**: GitHub activity and repo data refresh on every build.
- **Maintained through PRs**: AI agents write the changes, I review and merge them.

## What it is

The site you are reading: my portfolio and the single entry point for hiring. It is made for a hiring manager who wants to see how I think without opening 10 different links.

<details>
<summary>The problem and the decision</summary>

Most portfolios go stale within a month: GitHub activity stops updating, SEO is broken, projects are a list of names without context. What I did instead:

- **A physical route per language.** English at `/`, Russian at `/ru/`, both fully indexable, no JS content swap.
- **GitHub data at build time.** The API, behind a build-time cache, feeds the heatmap and repo metadata.
- **Cases as product pages.** MDX instead of markdown blobs.
- **Structured data.** JSON-LD for Person and ProfilePage, plus robots.

</details>

<details>
<summary>Under the hood</summary>

Astro 5, TypeScript, MDX, GitHub Actions, GitHub Pages.

The site is itself the case study: the repo shows how I structure data, separate content from logic and organize CI/CD. Most questions about the site are answered in the code.

</details>
