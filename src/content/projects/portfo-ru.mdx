## Что это

Сайт, который вы сейчас читаете: моё портфолио и единая точка входа для найма. Он сделан для hiring-менеджера, которому нужно понять, как я думаю, не открывая 10 разных ссылок.

<details>
<summary>Задача и решение</summary>

Большинство портфолио устаревают за месяц: GitHub-активность не обновляется, нормального SEO нет, проекты сведены к списку названий без контекста. Что я сделал вместо этого:

- **Свой физический роут на каждый язык.** Английский на `/`, русский на `/ru/`, обе версии индексируются полностью, без подмены контента через JS.
- **Данные GitHub на этапе сборки.** API за build-time кэшем питает heatmap и метаданные репозиториев.
- **Кейсы как продуктовые страницы.** MDX вместо маркдаун-блобов.
- **Structured data.** JSON-LD для Person и ProfilePage, плюс robots.

</details>

<details>
<summary>Под капотом</summary>

Astro 5, TypeScript, MDX, GitHub Actions, GitHub Pages.

Сайт сам по себе и есть кейс: в репозитории видно, как я структурирую данные, разделяю контент и логику, организую CI/CD. На большинство вопросов по сайту ответ лежит в коде.

</details>
